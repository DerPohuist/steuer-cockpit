# Steuer-Cockpit

Web-App für Angebote, Rechnungen und Belege. Statische Seite, läuft über GitHub Pages.

- `index.html` enthält die ganze App (HTML, CSS, JS).
- Daten liegen nur im Browser des Geräts (IndexedDB). Sicherung als JSON über Reiter „Firma“.
- Erste Ausbaustufe laut Konzept: Upload-Menü, Angebote, Rechnungen (PDF und XRechnung), Belege, Umsatzsteuer-Schätzung.
- Noch nicht drin: Login und Server, Texterkennung, Bankabgleich, ELSTER.
